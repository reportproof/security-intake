# Security Policy

This repository is an early security tooling project. Please report suspected vulnerabilities through GitHub private vulnerability reporting when available, or by opening a public issue only if the report does not expose exploitable details.

Useful reports should include:

- Affected version or commit.
- Affected component, endpoint, package, or file.
- Reproduction steps.
- Observed result and expected result.
- Concrete security impact.
- Proof of concept, logs, test, trace, or other evidence.
- Tested environment.

Reports that only contain speculative impact, scanner output, or AI-generated claims without reproducible evidence may be closed as incomplete.
