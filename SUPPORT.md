# Support

`security-intake` is an early open-source validation project.

## Public support

Use GitHub issues for:

- Sanitized report examples.
- Rule gaps or false positives.
- Workflow feedback.
- Documentation corrections.

## Out of scope

This project does not provide:

- Emergency vulnerability triage.
- Legal or compliance advice.
- Final vulnerability adjudication.
- Exploit development.
- Managed bug bounty services.

## Private vulnerability reports

Do not post private exploit details publicly. Use GitHub private vulnerability reporting when available.
