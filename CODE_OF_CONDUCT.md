# Code of Conduct

Reportproof is a technical project for improving security report intake. Public discussion should stay specific, respectful, and evidence-based.

## Expected behavior

- Be direct about technical issues without attacking people.
- Use sanitized examples when discussing security reports.
- Assume legitimate reporters and maintainers may both be under time pressure.
- Keep criticism tied to rules, outputs, documentation, or workflows.

## Unacceptable behavior

- Posting private exploit details in public issues.
- Harassment, personal attacks, or discriminatory language.
- Demanding emergency triage through this repository.
- Using the project to shame reporters, maintainers, or projects.

Maintainers may edit, hide, or close issues that violate these expectations.
